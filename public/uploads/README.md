# 업로드 이미지 (관리자 화면에서 올리는 사진)

Pages CMS의 미디어 폴더다. 여기에 올린 파일은 그대로 배포되어
`/uploads/<파일이름>` 주소로 열린다. (`public/` 아래라 정적 내보내기에 포함됨)

- **프로젝트 썸네일**: 프로젝트 편집 화면의 "썸네일"에서 이미지를 고르면
  `scripts/make-thumbnails.mjs`가 빌드 때 웜톤 4:3 프레임을 입힌
  `public/thumbnails/<슬러그>.png`를 만들고, 카드에는 그 프레임본이 보인다.
  (원본 비율·크기는 상관없음)
- **본문 사진**: 프로젝트 본문에 끼워 넣으면 `/uploads/...` 경로로 들어간다.
- **홈 히어로 이미지**: 사이트 문구 → "홈 히어로 이미지"에서 교체.

썸네일을 지정하지 않고 `/thumbnails/<슬러그>.png`를 그대로 쓰면
(스크린샷 없이 만든 이니셜 placeholder) 프레임 생성을 건너뛰고 그 파일을 쓴다.
